# 基于 0-1 规划的短期旅行决策模型 (Python 实现)

## 📌 项目背景
本项目源自 2026 年深圳北理莫斯科大学数学建模协会招新模拟赛 C 题。针对大学生短期旅行面临的“预算与时间双重约束”问题，建立 0-1 规划模型，旨在为旅客提供总兴趣值最大化的最优目的地及游玩项目组合。

原方案使用 WPS 表格结合 `SUMPRODUCT` 和 `IF` 函数进行枚举。本项目将其重构为 Python 工程化代码，实现了从数据管理、组合枚举、敏感性分析到高级可视化的全自动流水线。

## ✨ 核心功能
- **自动枚举**：利用 `itertools.product` 遍历每个城市 \(2^5=32\) 种项目组合。
- **多级排序**：在预算与时间约束下，按“总兴趣值降序、总费用升序、总时间升序”自动筛选全局最优解。
- **敏感性分析**：扫描 1500~2100 元预算区间，精准定位最优目的地转移的关键节点（1610元、1784元）。
- **时间稳定性检验**：将所有项目耗时增加 20%，检验原决策方案的鲁棒性。
- **可视化展示**：利用 `matplotlib` 绘制发表级阶梯折线图。

## 🛠️ 技术栈
- Python 3
- Pandas / Numpy (数据处理)
- Matplotlib (数据可视化)

## 🚀 运行指南
1. 克隆仓库并进入目录
2. 创建并激活虚拟环境（`.venv`）
3. 安装依赖：`pip install -r requirements.txt`
4. 运行脚本：
   - 求解问题一：`python solver.py`
   - 求解问题二：`python problem2.py`
   - 求解问题三：`python problem3.py`
   - 生成图表：`python plot_budget.py`

## 📊 项目成果
- **问题一**：1800元预算下，最优目的地为**长沙**，推荐项目“湖南博物院、岳麓书院、黄兴路步行街、长沙世界之窗”，总花费1784元，总兴趣值**37分**。
- **问题二**：预算达1610元时桂林反超厦门；预算达1784元时长沙反超桂林。
- **问题三**：耗时增加20%后，目的地依然是长沙，但模型自动剔除耗时过长的“长沙世界之窗”，替换为“橘子洲”，总兴趣值降为34分。
